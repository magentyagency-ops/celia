# What a tear can tell

Présentation animée (anglais) sur les protéines des larmes et le diabète de type 1.

- Ouvrir `index.html` (ou le site GitHub Pages).
- **Télécommande** : touche **R** (ou bouton téléphone) → scanner le QR code → boutons Suivant / Précédent sur le téléphone.
- Clavier : → suivant, ← précédent, F plein écran, N notes, O sommaire, T thème, B écran noir.
